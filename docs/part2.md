## 5. 学习工具

### 5.1 灵修阅读

系统支持 **SME (Standard Module Edition) / Daily OSIS** 格式的每日灵修内容解析与展示。

#### 操作步骤：

1. 在首页或菜单中点击 **「灵修」** 或 **「每日灵修」**
2. 系统自动显示当天的灵修内容
3. 可翻页查看前一天或后一天的灵修
4. 灵修内容引用的经文可点击跳转到圣经阅读界面

`[截图：每日灵修阅读界面]`

### 5.2 地图功能

系统内置 **3 个地图集**，共 **18 张地图**，支持缩放、全屏和拖拽操作。

#### 操作步骤：

1. 在菜单中点击 **「地图」** 或 **「圣经地图」**
2. 选择地图集（提供多个地图集）
3. 选择具体地图
4. 支持的操作：
   - **鼠标滚轮**：缩放地图
   - **鼠标拖拽**：平移地图
   - **全屏按钮**：进入全屏模式
   - **ESC**：退出全屏模式

`[截图：圣经地图查看界面]`

### 5.3 读经计划

系统提供多种读经计划，支持打卡功能。

#### 可用读经计划：

| 计划名称 | 周期 | 说明 |
|----------|------|------|
| M'Cheyne 读经计划 | 365天 | 全年读完旧约一遍、新约两遍 |
| 新约读经计划 | 90天 | 90天读完新约全书 |
| 箴言读经计划 | 30天 | 30天读完箴言全书 |

#### 操作步骤：

1. 在菜单中点击 **「读经计划」**
2. 选择一个读经计划
3. 查看今日读经内容
4. 阅读完毕后点击 **「打卡」** 按钮

#### 打卡方式：

| 用户状态 | 打卡方式 | 说明 |
|----------|----------|------|
| 游客 | localStorage | 打卡数据存储在浏览器本地，更换设备或清除缓存后丢失 |
| 登录用户 | 云端存储 | 打卡数据存储在服务器，跨设备同步 |

#### 查看进度：

1. 在读经计划页面可查看进度条
2. 显示已完成天数 / 总天数
3. 显示完成百分比
4. 可查看历史打卡记录

`[截图：读经计划进度页面]`

## 6. 课程系统

### 6.1 课程概览

系统提供 **3 门门徒训练课程**，共 **39 课**：

| 课程名称 | 课数 | 说明 |
|----------|------|------|
| 新生命 | 12课 | 基础信仰入门课程 |
| 新生活 | 12课 | 信仰生活实践课程 |
| 一对一门徒训练 | 15课 | 深度门徒训练课程 |

访问 `http://localhost:3000/courses.html` 进入课程页面。

`[截图：课程列表页面]`

### 6.2 课程学习

> **注意**：需要登录为 USER 或以上角色。

#### 操作步骤：

1. 访问 `http://localhost:3000/courses.html`
2. 浏览课程列表，选择一门课程
3. 点击 **「开始学习」** 进入课程
4. 按顺序阅读课程内容
5. 完成每课的学习后进入答题环节

### 6.3 答题系统

系统自动从课程内容中提取题目，支持以下题型：

| 题型 | 说明 | 评分方式 |
|------|------|----------|
| 填空题 | 根据课程内容自动提取关键术语 | 自动评分 |
| 选择题 | 根据课程内容自动生成单项/多项选择 | 自动评分 |
| 主观题 | 开放式思考题 | 教师手动阅卷 |

#### 答题流程：

1. 完成课程阅读后，点击 **「开始答题」**
2. 逐题作答
3. 填空题：在输入框中填写答案
4. 选择题：勾选正确选项
5. 主观题：在文本框中详细作答
6. 完成所有题目后点击 **「提交」**
7. 系统自动评分填空题和选择题
8. 主观题等待教师阅卷

`[截图：答题界面]`

### 6.4 自动评分

- 提交后，系统立即对**填空题**和**选择题**进行自动评分
- 主观题状态标记为「待阅卷」
- 可在课程进度页面查看各题得分和正确答案

### 6.5 教师阅卷

> **注意**：需要 TEACHER 或以上角色。

#### 操作步骤：

1. 登录后进入课程管理页面
2. 查看待阅卷列表
3. 选择学生提交的主观题答案
4. 阅读答案后给出评分和评语
5. 点击 **「提交评分」**

### 6.6 证书颁发

- 课程全部课程完成且答题合格后
- 系统自动颁发课程完成证书
- 证书包含学员姓名、课程名称、完成日期等信息
- 可在个人中心查看已获证书

`[截图：课程完成证书]`

### 6.7 课程管理（教师）

> **注意**：需要 TEACHER 或以上角色。

#### 可执行操作：

- 查看所有学员的学习进度
- 管理课程内容（新增/编辑/删除课程）
- 查看学员答题情况
- 进行主观题阅卷
- 颁发/撤销证书

`[截图：课程管理界面]`

## 8. 知识库语义搜索

### 8.1 知识库概览

系统知识库集成了**多模型语义搜索**功能，可从以下三大来源中进行智能检索：

| 数据来源 | 内容 |
|----------|------|
| 圣经 | 22+ 译本经文 |
| 图书馆 | 64 本中文属灵书籍 |
| 词典 | 35 本词典条目 |

### 8.2 向量模型

系统采用**多模型融合**策略进行语义向量编码：

| 模型 | 维度 | 用途 |
|------|------|------|
| TF-IDF | 256维 | 关键词匹配，快速检索 |
| BGE-small | 512维 | 轻量级语义检索 |
| BGE-base | 768维 | 高精度语义检索 |

多模型联合搜索可兼顾检索速度和准确性。

### 8.3 使用知识库搜索

#### 操作步骤：

1. 访问 `http://localhost:3000/plugins/knowledge-base/index.html`
2. 在搜索框中输入查询内容（自然语言提问）
3. 可选择搜索范围：
   - 全部来源
   - 仅圣经
   - 仅图书馆
   - 仅词典
4. 可选择使用的向量模型（默认多模型联合）
5. 点击搜索按钮或按 `Enter` 键
6. 搜索结果按相关度排序展示，包含：
   - 来源标记（圣经/图书馆/词典）
   - 匹配文本片段
   - 相关度评分
   - 可点击跳转到原文

#### 搜索示例：

- `「爱邻如己」` — 搜索相关经文和书籍论述
- `「因信称义」` — 搜索罗马书相关内容和神学书籍
- `「什么是恩典」` — 搜索词典定义和书籍解释

`[截图：知识库搜索结果页面]`

### 8.4 搜索技巧

1. **使用自然语言**：知识库支持语义搜索，无需使用精确关键词
2. **选择合适的来源**：如只查经文，选择「仅圣经」可提高准确性
3. **多模型对比**：对比不同模型的搜索结果，获取更全面的信息
4. **结合关键词**：在语义搜索的基础上加入具体关键词可缩小范围

## 9. 词典独立页面

### 9.1 词典概览

系统内置 **35 本词典**，支持中英对照名称，可通过独立页面进行浏览和搜索。

访问 `http://localhost:3000/dictionary.html` 进入词典页面。

`[截图：词典独立页面]`

### 9.2 浏览词典

1. 访问词典页面
2. 左侧栏列出所有可用词典
3. 选择一本词典
4. 浏览词典条目列表
5. 点击条目查看详细内容

### 9.3 搜索词典

1. 在词典页面顶部搜索框中输入关键词
2. 可选择搜索范围（某本词典或全部词典）
3. 点击搜索按钮
4. 搜索结果列出匹配条目

### 9.4 URL参数直达条目

系统支持通过 URL 参数直接访问特定词典条目，方便分享和引用：

```
http://localhost:3000/dictionary.html?dict=StrongHebrew&entry=H430
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `dict` | 词典名称 | `StrongHebrew`、`StrongGreek`、`Nave` |
| `entry` | 条目名称或编号 | `H430`、`G2316`、`faith` |

#### 常用词典列表：

| 词典名称 | 说明 | 条目数 |
|----------|------|--------|
| Strong's Hebrew | 希伯来文 Strong's 词典 | 8,674 |
| Strong's Greek | 希腊文 Strong's 词典 | 5,667 |
| Nave | Nave 主题词典 | — |
| Easton | Easton 圣经词典 | — |
| 其他 | 更多专业词典 | — |

### 9.5 词典与圣经阅读联动

在圣经阅读界面中：

1. 点击带 Strong's 编号的词汇，自动跳转到词典页面对应条目
2. 词典条目页面可链接回相关经文
3. 支持在阅读时同时打开词典页面进行对照
