## 1. 系统简介

Bible Microservices 是一个在线圣经学习系统，集多译本阅读、逐词对照、词典查询、注释、灵修、地图、读经计划、在线课程和知识库语义搜索于一体。

### 核心数据

| 项目 | 数量 |
|------|------|
| 圣经译本 | 22+（中/英/希腊/希伯来） |
| SWORD 模块 | 123 个 |
| Strong's 词典条目 | 14,341（希伯来 8,674 + 希腊 5,667） |
| 注释源 | 34 个 |
| 词典 | 35 本 |
| 地图 | 3 集 18 张 |
| 读经计划 | 3 个 |
| 在线课程 | 3 门 39 课 |
| 图书馆藏书 | 64 本 |
| 知识库向量 | 433,000+ |

### 访问地址

| 页面 | URL |

## 2. 快速开始

### 2.1 首次访问

1. 打开浏览器，访问 `http://localhost:3000/`
2. 系统默认显示中文双语界面
3. 默认译本为 WEB（英文），可在顶部下拉切换

### 2.2 界面布局

```
┌─────────────────────────────────────────────┐
│  [Logo] 📖📖 📱 [语言▼] [更多▼]              │  ← 顶部工具栏
├──────────┬──────────────────────────────────┤
│          │                                    │
│  书卷    │     经文内容区                     │
│  选择    │                                    │
│  栏      │                                    │
│          │                                    │
├──────────┴──────────────────────────────────┤
│ [译本▼] [章节▼] [Interlinear] [TTS] ...     │  ← 功能栏
└─────────────────────────────────────────────┘
```

### 2.3 语言切换

- 点击顶部工具栏的 **语言下拉框**
- 三种模式：**中文** / **English** / **双语**（默认）
- 双语模式下，所有 UI 文本同时显示中英文

## 3. 用户账号

### 3.1 注册

1. 点击顶部 **登录** 按钮
2. 切换到 **注册** 标签
3. 填写：用户名（≥2字符）、密码（≥3字符）、验证码（数学题）
4. 点击 **注册**

### 3.2 登录

1. 点击顶部 **登录** 按钮
2. 输入用户名、密码、验证码
3. 登录后 JWT 有效期 24 小时
4. 顶部显示用户名和角色

### 3.3 角色

| 角色 | 权限 |
|------|------|
| 游客 | 读经、搜索、词典、地图、灵修、读经计划(localStorage) |
| USER | + 书签笔记、读经计划云端打卡、课程学习答题 |
| TEACHER | + 课程管理、阅卷 |
| ADMIN | + 用户管理、模块安装、系统设置 |

### 3.4 修改密码

登录后：点击顶部用户名 → **修改密码** → 输入旧密码和新密码

| OSHB | 希伯来文圣经 | SWORD |

### 4.2 选择书卷和章节

- 左侧栏点击书卷名 → 选择章节号

1. 在功能栏点击 **对照** 按钮

|------|------|------|
| translation | 译本代码 | cuv_gb |

## 5. 逐词对照（Interlinear）

### 5.1 什么是 Interlinear

逐词对照（Interlinear）将原文（希伯来文/希腊文）与译文逐词对齐，每个词附带 Strong's 编号和形态标注。

### 5.2 启用 Interlinear

1. 在功能栏点击 **Interlinear** 按钮
2. 系统自动检测当前译本是否支持 Interlinear
3. 支持的译本会显示逐词对照内容

### 5.3 支持的译本

| 译本 | 语言 | 说明 |
|------|------|------|
| KJV | 英文 | 完整 Strong's 标注 |
| ChiUns | 中文新译本 | Strong's 标注 |
| ChiUn | 中文 Union | Strong's 标注 |
| BSB | 英文 | 希腊/希伯来文 |
| OSHB | 希伯来文 | 原文形态 |
| SP | 撒玛利亚五经 | 希伯来文 |
| LXX | 七十士译本 | 希腊文 |

### 5.4 形态学标注

- 每个词上方显示 `<sup>` 形态码
- 鼠标悬停形态码显示语法解释
- 覆盖 406+ 形态码（Qal/Niphal/Piel/Pual/Hiphil 等）

## 6. Strong's 词典

### 6.1 悬停查询

- Interlinear 模式下，鼠标悬停带 Strong's 编号的词

### 6.2 直接搜索

- 顶部搜索栏输入 Strong's 编号（如 H430、G2424）
- 或访问 Strong's 词典页直接查询

### 6.3 编号格式

| 前缀 | 语言 | 范围 |
|------|------|------|
| H | 希伯来文 | H1–H8674 |
| G | 希腊文 | G1–G5667 |

> 注意：前端自动去除前导零（H0853 → H853）

## 14. 答题系统

### 14.1 题目类型

| 类型 | 提取方式 | 评分方式 |
|------|----------|----------|
| 填空题 | `____` 下划线标记 | 自动（精确匹配） |
| 选择题 | `是（）不是（）` 模式 | 自动 |
| 简答题 | 手动创建 | 教师手动阅卷 |
| 论述题 | 手动创建 | 教师手动阅卷 |

### 14.2 考试流程

1. 课程所有课时完成后 → 进入考试
2. 逐题作答 → 提交
3 选择题/填空题：自动评分
4. 简答题/论述题：等待教师阅卷
5. 全部阅卷完成 → 显示总分
6. ≥ 60 分及格 → 自动颁发证书

### 14.3 证书

- 及格后自动生成
- 含唯一验证码
- 证书验证页：`http://localhost:3000/certificates/verify/{code}`

### 14.4 教师阅卷

1. 教师登录 → 课程管理 → 待阅卷列表
2. 逐题查看学生答案 → 给分 → 提交

## 20. 常见问题 FAQ

### Q: 页面显示空白或样式错乱？
A: 按 **Ctrl+F5** 硬刷新清除浏览器缓存。跨会话修改 JS 后必须硬刷新。

### Q: 切换译本后没有经文显示？
A: 部分译本（如 Byz、OSHB）的 text API 返回 0 节，系统会自动回退到 SWORD API。如仍为空，检查后端是否运行。

### Q: Interlinear 按钮不显示？
A: Interlinear 仅对支持 Strong's 标注的译本显示（KJV/ChiUns/ChiUn/BSB/OSHB/SP/LXX）。

### Q: 注释只显示 3 个源？
A: 注释源数量取决于后端 SWORD 模块安装情况。完整安装后有 34 个源。如果只看到 3 个，可能是部分模块未安装。

### Q: 全文搜索中文译本无结果？
A: Lucene 索引目前仅覆盖 8 个英文译本。中文译本搜索请使用 SWORD API 回退或知识库语义搜索。

### Q: 读经计划打卡丢失？
A: 未登录用户的打卡存储在浏览器 localStorage，清除浏览器数据会丢失。登录用户打卡存储在服务器数据库，不会丢失。

### Q: 知识库搜索结果太少？
A: 尝试切换模型（BGE-small/BGE-base 比 TF-IDF 语义匹配更好）或切换搜索模式（混合搜索比纯向量搜索覆盖更广）。

### Q: 课程考试提交后一直等待？
A: 主观题（简答/论述）需要教师手动阅卷。联系课程教师完成阅卷后才能看到总分。

### Q: 手机版白底白字？
A: 确认 CSS 版本号已更新。按 Ctrl+F5 硬刷新。如果问题持续，检查浏览器是否支持 CSS 变量。

### Q: 如何部署到服务器？
A: 参见《运维人员手册》和《部署说明》文档。

### Q: 管理员默认密码？
A: admin / admin123。**首次登录后请立即修改密码**。

A: Chrome 90+、Edge 90+、Firefox 88+、Safari 14+。不支持 IE。
