## 1. 系统简介

### 1.1 系统概述

Bible Microservices 是一套基于 Spring Boot + Kotlin 构建的在线圣经学习系统，采用单体部署模式，集成了圣经阅读、原文研究、课程学习、词典查询、图书馆阅读和知识库语义搜索等多种功能。

系统内置 **123 个 SWORD 模块**，包括 16 个圣经译本、5 个词典、1 个注释、3 个通用书等，H2 数据库容量约 231MB，涵盖 22+ 译本、35 本词典、34 个注释源、3 个地图集，以及 64 本中文属灵书籍和 3 门门徒训练课程（共 39 课）。

### 1.2 技术架构

| 组件 | 技术栈 | 端口 |
|------|--------|------|
| 后端服务 | Spring Boot 3.x + Kotlin + H2 + JSword | 8080 |
| 前端服务 | Node.js 静态服务（桌面版 + 手机版） | 3000 |

### 1.3 访问地址

| 页面 | 地址 |
|------|------|
| 桌面版首页 | http://localhost:3000/ |
| 手机版首页 | http://localhost:3000/m/ |
| 词典页面 | http://localhost:3000/dictionary.html |
| 课程页面 | http://localhost:3000/courses.html |
| 图书馆页面 | http://localhost:3000/library.html |
| 知识库页面 | http://localhost:3000/plugins/knowledge-base/index.html |
| 管理后台 | http://localhost:3000/admin.html |
| 模块管理 | http://localhost:3000/modules.html |
| 系统设置 | http://localhost:3000/settings.html |
| 登录页面 | http://localhost:3000/login.html |

### 1.4 用户角色

系统分为四种用户角色，权限由低到高依次为：

| 角色 | 权限范围 |
|------|----------|
| **游客** | 读经、搜索、词典查询、地图浏览、灵修、读经计划（本地打卡） |
| **USER** | 游客全部权限 + 书签、笔记、读经计划云端打卡、课程学习与答题 |
| **TEACHER** | USER全部权限 + 课程管理、主观题阅卷 |
| **ADMIN** | TEACHER全部权限 + 用户管理、模块安装、系统设置 |

## 2. 快速开始

### 2.1 系统启动

#### 2.1.1 启动后端服务

```bash
# 进入项目目录
cd D:\dev\github\bible-microservices

# 启动后端 JAR（端口 8080）
java -jar bible-monolith.jar
```

启动成功后，控制台将显示 Spring Boot 启动信息，后端服务运行在 `http://localhost:8080`。

#### 2.1.2 启动前端服务

```bash
# 进入前端目录
cd D:\dev\github\bible-microservices\frontend

# 安装依赖（首次启动）
npm install

# 启动前端服务（端口 3000）
npm start
```

启动成功后，浏览器访问 `http://localhost:3000/` 即可进入系统首页。

`[截图：系统首页 - 桌面版]`

### 2.2 首次使用

1. 打开浏览器，访问 `http://localhost:3000/`
2. 系统默认以**游客身份**展示圣经阅读界面
3. 如需使用书签、笔记、课程等功能，请先注册/登录（参见 [第3章](#3-用户账户管理)）

### 2.3 手机版访问

在手机浏览器中输入 `http://localhost:3000/m/`（如果服务器在同一局域网，请将 `localhost` 替换为服务器 IP）。

`[截图：手机版首页]`

### 2.4 推荐浏览器

为获得最佳使用体验，建议使用以下浏览器：

- **Chrome** 90+（推荐）
- **Edge** 90+
- **Firefox** 88+
- **Safari** 14+

## 3. 用户账户管理

### 3.1 注册账户

1. 点击页面右上角 **「登录」** 按钮或直接访问 `http://localhost:3000/login.html`
2. 在登录页面点击 **「注册新账户」** 链接
3. 填写以下信息：
   - **用户名**：3-32 个字符，支持字母、数字、下划线
   - **密码**：至少 6 位
   - **邮箱**（可选）：用于密码找回
4. 输入数学验证码（例如：`3 + 7 = ?`）
5. 点击 **「注册」** 按钮

`[截图：注册页面]`

### 3.2 登录

1. 访问 `http://localhost:3000/login.html`
2. 输入用户名和密码
3. 输入数学验证码
4. 点击 **「登录」** 按钮
5. 登录成功后，系统签发 JWT 令牌（有效期 42 小时），无需频繁登录

> **提示**：JWT 令牌有效期 42 小时，在此期间内刷新页面或重开浏览器无需重新登录。

### 3.3 退出登录

点击页面右上角的用户名下拉菜单，选择 **「退出登录」**，系统将清除本地 JWT 令牌。

### 3.4 角色权限矩阵

## 4. 圣经阅读

### 4.1 打开圣经阅读

- 桌面版：访问 `http://localhost:3000/`
- 手机版：访问 `http://localhost:3000/m/`

系统默认展示创世记第1章（或上次阅读位置）。

`[截图：圣经阅读主界面 - 桌面版]`

### 4.2 切换译本

系统内置 **22+ 个圣经译本**，包括中文、英文等多种语言版本。

#### 操作步骤：

1. 在阅读界面顶部或侧边栏找到 **译本选择器**
2. 点击下拉菜单，列出所有可用译本
3. 选择目标译本，阅读区域将立即切换

#### 支持的主要译本（部分）：

| 类型 | 译本名称 |
|------|----------|
| 中文 | 和合本（CUV）、新译本（CNV）、吕振中译本 |
| 英文 | KJV、ESV、NIV、NASB、WEB、ASV 等 |
| 原文 | 希伯来文旧约（BHS）、希腊文新约（TR/NA28） |
| 对照 | 多个带有 Strong's 编号的译本 |

### 4.3 多译本对照阅读

1. 在译本选择器中勾选 **「对照模式」**
2. 选择 2-4 个译本进行并排对照显示
3. 每个译本以独立列展示，方便对比翻译差异

`[截图：多译本对照阅读界面]`

### 4.4 逐词对照（Interlinear）

系统支持 **7 个译本** 的逐词对照功能，带有 Strong's 编号。

#### 操作步骤：

1. 选择支持 Interlinear 的译本（如带有 Strong's 标记的版本）
2. 点击工具栏的 **「Interlinear」** 按钮启用逐词对照
3. 每个原文词汇将显示在对应译词下方

> **说明**：Interlinear 功能依赖以下数据：
> - 希伯来文 Strong's 词典：8,674 个词条
> - 希腊文 Strong's 词典：5,667 个词条

`[截图：逐词对照界面]`

### 4.5 Strong's 词典悬停

当阅读带 Strong's 编号的译本时：

1. 将鼠标悬停在带有下划线的词汇上
2. 系统自动弹出 Strong's 词典条目
3. 弹窗内容包括：
   - **原文词汇**（希伯来文/希腊文）
   - **音标**（拉丁转写）
   - **Strong's 编号**（如 H430、G2316）
   - **释义**（中英双语）
   - **词性**（名词、动词等）
4. 点击弹窗中的编号可跳转到完整的 Strong's 词典页面

> **统计**：系统包含希伯来文 Strong's 词条 8,674 个，希腊文 Strong's 词条 5,667 个。

`[截图：Strong's 词典悬停弹窗]`

### 4.6 形态学标注

系统支持 **406+ 个形态学编码**，在 Interlinear 模式下可查看每个词汇的：

- 词性（名词、动词、形容词等）
- 时态（仅希腊文：现在、过去、将来等）
- 语态（主动、被动、中间）
- 语气（直说、命令、虚拟等）
- 人称与数（第一/二/三人称，单/复数）
- 性（阳性、阴性、中性）

### 4.7 经文注释

系统内置 **34 个注释源**，为经文提供详细的解释和背景。

#### 操作步骤：

1. 在阅读界面中，注释可用的经节旁边会显示注释图标
2. 点击图标，注释内容将在侧边栏或弹窗中展示
3. 可在设置中切换不同注释源

`[截图：经文注释侧边栏]`

### 4.8 全文搜索

系统基于 **Lucene 索引**，支持 **8 个英文译本** 的全文搜索。

#### 操作步骤：

1. 点击页面顶部搜索框或使用快捷键 `Ctrl + K`（桌面版）
2. 输入搜索关键词
3. 选择搜索范围（某个译本或所有可用译本）
4. 点击搜索按钮或按 `Enter` 键
5. 搜索结果列表显示匹配经文，点击可跳转到对应章节

#### 搜索技巧：

| 语法 | 说明 | 示例 |
|------|------|------|
| 精确词组 | 使用引号 | `"love your enemy"` |
| 多词搜索 | 空格分隔 | `faith hope love` |
| 通配符 | `*` 或 `?` | `light*` |
| 布尔搜索 | AND / OR / NOT | `faith AND works` |

`[截图：全文搜索结果页面]`

### 4.9 书签功能

> **注意**：需要登录为 USER 或以上角色。

#### 添加书签：

1. 在阅读界面中，将鼠标悬停在目标经节上
2. 经节右侧出现工具按钮
3. 点击 **书签图标** 添加书签
4. 可选填写书签备注

#### 管理书签：

1. 点击侧边栏或菜单中的 **「书签」** 标签
2. 查看所有已收藏书签
3. 点击书签可跳转到对应经文
4. 可编辑备注或删除书签

`[截图：书签管理界面]`

### 4.10 笔记功能

> **注意**：需要登录为 USER 或以上角色。

#### 添加笔记：

1. 在阅读界面中，将鼠标悬停在目标经节上
2. 点击 **笔记图标**
3. 在弹出的编辑框中输入笔记内容
4. 支持 Markdown 格式
5. 点击 **「保存」** 按钮

#### 管理笔记：

1. 在侧边栏查看所有笔记列表
2. 点击笔记跳转到对应经文
3. 可编辑或删除笔记

`[截图：笔记编辑界面]`

### 4.11 章节导航

- **上一章 / 下一章**：阅读界面底部或顶部的导航箭头
- **跳转**：在地址栏输入卷名和章节号，如 `John 3:16` 或 `创世记 1`
- **书卷选择**：点击卷名可弹出书卷列表，选择目标书卷和章节
