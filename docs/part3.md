## 10. 管理后台

> **注意**：本章操作需要 ADMIN 角色。

### 10.1 进入管理后台

1. 访问 `http://localhost:3000/admin.html`
2. 需要以 ADMIN 角色登录
3. 管理后台提供以下功能模块：
   - 用户管理
   - 系统统计
   - 课程管理
   - 模块管理
   - 系统设置

`[截图：管理后台首页]`

### 10.2 用户管理

#### 可执行操作：

1. 在管理后台点击 **「用户管理」**
2. 查看所有用户列表
3. 搜索用户（按用户名、邮箱）
4. 修改用户角色（USER / TEACHER / ADMIN）
5. 启用/禁用用户账户
6. 重置用户密码
7. 查看用户活动统计

`[截图：用户管理界面]`

### 10.3 组织管理

- 系统支持组织管理功能
- 可创建/编辑/删除组织
- 将用户分配到组织
- 组织可用于课程分班、权限管理等

### 10.4 系统统计

管理后台提供系统运行统计数据：

- 用户总数、活跃用户数
- 课程完成统计
- 搜索热度统计
- 模块使用统计
- 系统资源使用情况

## 11. 模块管理

> **注意**：本章操作需要 ADMIN 角色。

### 11.1 模块概览

系统通过 SWORD 模块系统管理所有圣经译本、词典、注释、地图等资源。当前共 **123 个模块**。

访问 `http://localhost:3000/modules.html` 进入模块管理页面。

#### 模块类型分布：

| 类型 | 数量 | 说明 |
|------|------|------|
| 圣经译本 | 16 | 包含中英文多版本 |
| 词典 | 5 | 包含 Strong's 等 |
| 注释 | 1 | 经文注释 |
| 通用书 | 3 | 灵修、地图等 |
| 其他 | 98 | 扩展模块 |

### 11.2 查看模块列表

1. 访问 `http://localhost:3000/modules.html`
2. 查看所有已安装模块列表
3. 每个模块显示以下信息：
   - 模块名称
   - 类型（圣经/词典/注释/通用书/地图等）
   - 语言
   - 大小
   - 状态（已安装/未安装）

`[截图：模块管理列表页面]`

### 11.3 安装新模块

1. 在模块管理页面点击 **「安装新模块」**
2. 可通过以下方式安装：
   - 从在线仓库选择模块安装
   - 上传本地 SWORD 模块文件
3. 选择目标模块后点击 **「安装」**
4. 等待安装完成，安装进度会实时显示
5. 安装完成后模块自动出现在可用列表中

`[截图：模块安装界面]`

### 11.4 卸载模块

1. 在模块列表中找到目标模块
2. 点击 **「卸载」** 按钮
3. 确认卸载操作
4. 系统将移除该模块及相关索引数据

> **警告**：卸载模块将删除相关数据，请谨慎操作。建议在卸载前备份重要数据。

### 11.5 模块配置

1. 点击模块列表中的 **「配置」** 按钮
2. 可设置：
   - 模块显示名称
   - 模块排序
   - 是否在译本选择器中显示
   - 默认是否启用

## 14. 常见问题FAQ

### Q1: 系统无法访问，页面显示空白或报错？

**可能原因与解决方案**：

1. **后端服务未启动**：检查 `http://localhost:8080` 是否可访问
   - 解决：启动后端 JAR，查看控制台日志是否有错误
2. **前端服务未启动**：检查 `http://localhost:3000` 是否可访问
   - 解决：启动前端 Node.js 服务
3. **端口冲突**：8080 或 3000 端口被其他程序占用
   - 解决：停止占用端口的程序，或修改配置文件中的端口号
4. **防火墙拦截**：系统防火墙阻止了访问
   - 解决：在防火墙中放行 8080 和 3000 端口

### Q2: 登录后提示"令牌已过期"？

**说明**：JWT 令牌有效期为 42 小时。

**解决方案**：
1. 退出登录后重新登录
2. 系统将签发新的 JWT 令牌
3. 如频繁过期，联系管理员检查 JWT 过期时间设置

### Q3: 某些译本无法显示或显示乱码？

**可能原因与解决方案**：

1. **模块未安装**：该译本的 SWORD 模块未安装
   - 解决：管理员在模块管理页面安装对应模块
2. **字体缺失**：系统缺少显示该语言所需的字体
   - 解决：安装对应语言的字体（如希伯来文、希腊文字体）
3. **编码问题**：浏览器编码设置不正确
   - 解决：确保浏览器使用 UTF-8 编码

### Q4: 全文搜索搜不到中文内容？

**说明**：系统基于 Lucene 索引的全文搜索目前支持 **8 个英文译本**，暂不支持中文全文搜索。

**替代方案**：
1. 使用知识库语义搜索（支持中文）
2. 使用词典页面搜索中文关键词
3. 切换到英文译本后使用全文搜索

### Q5: 读经计划打卡数据丢失？

**可能原因**：
1. 以游客身份打卡 — 数据存储在浏览器 localStorage
2. 清除了浏览器缓存 — localStorage 数据被清除
3. 更换了设备或浏览器 — 数据无法跨设备同步

**解决方案**：
1. 注册并登录账户
2. 登录后打卡数据将存储在服务器云端
3. 支持跨设备同步

### Q6: 课程答题提交后没有显示成绩？

**说明**：课程题目分为自动评分和手动评分两种。

**解决方案**：
1. **填空题和选择题**：提交后立即自动评分，可查看成绩
2. **主观题**：需要等待教师阅卷，状态显示为「待阅卷」
3. 如长时间未出成绩，请联系课程教师或管理员

### Q7: 知识库搜索结果不相关？

**可能原因与解决方案**：

1. **搜索词过于宽泛**：尝试使用更具体的关键词
2. **来源范围过大**：缩小搜索范围（如仅搜索圣经）
3. **模型选择不当**：尝试切换不同的向量模型
4. **索引未更新**：联系管理员重建知识库向量索引

### Q8: 如何在手机上使用系统？

1. 在手机浏览器中输入 `http://localhost:3000/m/`
2. 如服务器在同一局域网，将 `localhost` 替换为服务器 IP
3. 手机版支持：圣经阅读、搜索、词典、灵修、读经计划
4. 建议将页面添加到主屏幕，以获得类似原生 App 的体验

### Q9: 管理员账户忘记了密码怎么办？

**解决方案**：

1. 通过后端命令行重置：
   ```bash
   java -jar bible-monolith.jar --reset-admin
   ```
2. 或直接修改 H2 数据库中的用户密码字段
3. 重置后使用默认密码登录，并立即修改密码

### Q10: 如何安装新的圣经译本？

1. 以 ADMIN 角色登录
2. 访问 `http://localhost:3000/modules.html`
3. 点击 **「安装新模块」**
4. 从在线仓库选择或上传本地 SWORD 模块文件
5. 等待安装完成
6. 安装后新译本将出现在译本选择器中

### Q11: 系统支持多少人同时使用？

**说明**：系统采用单体部署，使用嵌入式 H2 数据库。

- **推荐**：10-50 人同时使用
- **最大**：约 100 人并发（取决于服务器配置）
- 如需支持更多用户，建议：
  - 升级服务器硬件
  - 将 H2 数据库迁移到 MySQL/PostgreSQL
  - 增加缓存配置

### Q12: 可以在离线环境中使用吗？

**可以**。系统完全支持离线使用：

1. 后端 JAR 包含所有必需依赖
2. H2 数据库为嵌入式数据库，无需外部数据库服务
3. 所有 SWORD 模块已预装
4. 前端为静态文件，可离线服务

唯一需要网络连接的功能：
- 在线安装新模块（需要访问 SWORD 模块仓库）
- 知识库向量模型下载（首次部署时）

### Q13: 如何备份数据？

1. **H2 数据库备份**：
   - 管理员在系统设置中点击「数据库备份」
   - 或直接复制 H2 数据库文件
2. **用户数据备份**：
   - 包括用户账户、书签、笔记、读经打卡、课程进度等
   - 均存储在 H2 数据库中
3. **配置文件备份**：
   - 复制 `application.yml` 等配置文件

### Q14: 如何升级系统？

1. 备份当前数据库和配置文件
2. 停止当前运行的后端和前端服务
3. 替换 JAR 文件为新版本
4. 更新前端文件
5. 启动后端和前端服务
6. 系统将自动执行数据库迁移（如需要）

### Q15: Strong's 词典悬停不显示弹窗？

**可能原因与解决方案**：

1. **译本不支持**：当前译本没有 Strong's 编号数据
   - 解决：切换到带 Strong's 标记的译本
2. **JavaScript 被禁用**：浏览器禁用了 JS
   - 解决：启用 JavaScript
3. **弹窗被拦截**：浏览器弹窗拦截功能
   - 解决：允许本站弹窗
4. **Interlinear 模式未启用**：某些功能需要先开启 Interlinear
   - 解决：点击工具栏的 Interlinear 按钮
