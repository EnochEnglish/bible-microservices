# 需求文档 — Bible Microservices

## 1. 项目概述

### 1.1 项目目标
将 AndBible 的核心功能改造为本地运行/服务器部署的在线圣经学习系统，支持多译本对照、Strong's 词典、注释、逐词对照、地图、灵修、读经计划、在线课程和答题系统。

### 1.2 目标用户
- 神学院学生和教师
- 教会门徒培训
- 个人圣经学习
- 查经小组

### 1.3 核心价值
- **离线可用**：本地运行无需互联网
- **多译本**：22+ 译本对照阅读
- **原文学习**：Strong's 编号 + 形态学标注
- **课程系统**：内置门徒训练课程 + 在线答题
- **轻量部署**：单体 JAR + 静态前端，1GB 内存服务器即可

## 3. 非功能需求

### 3.1 性能
- 后端 JVM 内存：-Xms48m -Xmx256m
- H2 数据库：231MB，31102+ 经文
- 前端：无框架依赖，纯原生 JS

### 3.2 兼容性
- 浏览器：Chrome 90+, Firefox 88+, Safari 14+
- 手机：响应式设计，PWA manifest
- 服务器：1GB 内存即可运行

### 3.3 安全
- JWT 无状态认证（42h 过期）
- 验证码（HMAC 签名，5 分钟过期）
- 公共 API permitAll，管理 API 需 ADMIN 角色
- 不在前端存储敏感数据

### 3.4 可维护性
- 代码解耦：新功能独立文件
- 模块化：前端 IIFE 封装，后端 MVC 分层
- 文档：README + 技术文档 + 需求文档 + 部署说明

## 4. 用户故事

### 4.1 学生用户

**作为学生，我希望：**
1. 选择译本阅读圣经，切换章节
2. 开启 Interlinear 模式查看原文 Strong's 编号
3. 悬停 Strong's 编号查看词典解释
4. 查看注释了解经文解释
5. 报名课程，按课学习
6. 在课程内容中填写填空题答案并提交
7. 查看我的成绩和历史记录
8. 完成所有课程后获得证书
9. 使用读经计划每日打卡
10. 手机和桌面版无缝切换

### 4.2 教师用户

**作为教师，我希望：**
1. 创建课程和章节
2. 从课程内容自动提取题目生成考试
3. 查看待阅卷的主观题答案
4. 为每道主观题评分和批注
5. 查看全班成绩分布统计
6. 管理课程内容（增删改）

### 4.3 管理员

**作为管理员，我希望：**
1. 管理用户（创建/角色分配）
2. 管理组织
3. 配置系统设置
4. 管理 SWORD 模块（安装/卸载）
